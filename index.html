Featured · AI & Computer Vision

Sentinel – Roboflow Attendance Agent

A browser-based attendance system where an AI agent takes the roll-call. It captures a camera frame, sends it to a Roboflow detection model, matches the label to a registered student and marks them present, but only if the confidence passes a threshold you set.

  • Agent cycle: detect → identify → verify → decide → commit
  • Manual scan or autonomous scanning every 5, 8, 15 or 30 seconds
  • Never marks the same student twice on one day; low-confidence detections are discarded
  • Shows its reasoning live, with a dashboard, searchable records, CSV export and an activity log
  • Single HTML file with no server; demo mode lets the whole workflow run without a trained model
  • Passed 20 test cases (run twice); real-world accuracy depends on the model you connect
  • HTML / CSS / JavaScript
  • Roboflow
  • Computer Vision
  • localStorage

Arduino-Based Street Light System

A low-voltage prototype that switches a lamp on at dusk and off at dawn. An LDR light sensor feeds an Arduino UNO, which compares the reading to a darkness level and turns an LED on or off.

  • LDR and a fixed resistor form a voltage divider read on pin A0
  • LED on digital pin 9 through a 220–330 Ω resistor
  • Future ideas: motion sensors, PWM dimming, solar power, IoT monitoring
  • Arduino UNO
  • LDR sensor
  • C / Arduino
